# 한곳 색인 — 실행 방법

별도 프로그램 설치 없이 Windows에 기본으로 있는 PowerShell만으로 실행됩니다.

## 1. 실행
1. 이 폴더의 **`실행.bat`** 을 더블클릭합니다.
2. 검은 창이 뜨고 브라우저가 자동으로 `http://localhost:8787` 을 엽니다.
3. 처음 실행하면 Windows 방화벽 창이 뜰 수 있습니다. 휴대폰에서도 쓰려면 **"개인 네트워크"에 허용**을 누르세요.

> 검은 창이 켜져 있는 동안만 앱이 동작합니다. 끝낼 때는 창을 닫으면 됩니다.

## 2. 휴대폰에서 같은 자료 보기
- 휴대폰과 PC가 **같은 와이파이**에 연결되어 있어야 합니다.
- 검은 창에 표시된 `휴대폰에서 열기: http://192.168.x.x:8787` 주소를 휴대폰 브라우저에 입력합니다.
- 홈 화면에 추가해 두면 앱처럼 열 수 있습니다.
- 휴대폰에서 등록한 자료는 PC에 바로 저장되고, 반대도 마찬가지입니다. (다른 기기에서 바꾼 내용은 창으로 돌아오면 새로 불러옵니다.)

## 3. 데이터
- 모든 자료는 이 폴더의 **`data.json`** 한 파일에 저장됩니다. 백업은 이 파일을 복사하면 됩니다.
- 처음 실행 시 `seed.json`의 **[예시] 샘플 8건**이 들어갑니다. 확인 후 카드를 눌러 삭제하세요.
- 처음 상태로 되돌리려면 앱을 끄고 `data.json`을 지운 뒤 다시 실행합니다.
- 서버 없이 `index.html`만 열면 "이 브라우저에만 저장" 모드(안전망)로 동작합니다. 이때는 기기 간 공유가 되지 않습니다.

## 4. 사용법
- **검색**: 상단 검색창에 단어 입력 → 제목·위치·위치 상세·핵심 내용에서 즉시 걸러지고 일치 부분이 강조됩니다.
- **보관 위치 필터**: 검색창 아래 버튼(전체/노션/카톡/…)
- **등록**: 오른쪽 아래 "＋ 새 자료 등록"
- **수정·삭제**: 카드를 누르면 카드 안에 버튼이 나옵니다.

## 5. 주의
- 비밀·대외비 내용은 적지 말고 **위치만** 기록하세요.
- 같은 와이파이의 다른 사람도 주소를 알면 접속할 수 있습니다. 공용 와이파이(카페, 교육장 등)에서는 PC에서만 쓰거나 사용 후 창을 닫으세요.

## 문제 해결
| 증상 | 해결 |
|---|---|
| "8787 포트를 열 수 없습니다" | 이미 실행 중인 검은 창이 있는지 확인하고 닫은 뒤 다시 실행 |
| 휴대폰에서 접속이 안 됨 | 같은 와이파이인지 확인 → Windows 방화벽에서 PowerShell 허용 → 회사·교육장 와이파이는 기기 간 접속을 막아둔 경우가 많음 |
| 창이 바로 꺼짐 | `실행.bat` 대신 PowerShell에서 `powershell -ExecutionPolicy Bypass -File .\server.ps1` 실행 후 오류 메시지 확인 |
